Android client for Hermes Agent

Your agent. In your pocket.

Apollo connects your phone to the Hermes Agent running on your own computer. Chat, approve tools, resume sessions and share files from anywhere, privately over Tailscale.

Download APK Set up Hermes

Free and open source. Android 8 or newer. No account, no cloud, no telemetry.

Features

#1 Chat

Talk to your agent

Live streaming replies, Markdown and code, tool calls with their results, reasoning, images and slash commands. Steer, stop, branch or compress a session, or talk hands-free in a voice conversation.

#2 Private

Private by design

Hermes stays on your computer. Tailscale Serve gives you HTTPS inside your tailnet, with no open ports. Credentials live in encrypted storage on the phone.

#3 Approve

Tools on your terms

Approve tool calls, answer clarify questions and sudo or secret prompts in the chat, or straight from a notification.

#4 Remember

Sessions that follow you

Browse, search, pin and resume sessions, grouped by project. After a dropped connection Apollo replays what you missed.

#5 Automate

Cron and webhooks

Create and watch scheduled jobs and webhooks, and get notified when a task finishes.

#6 Organise

Projects, Kanban, files

Kanban boards, projects, skills, MCP servers and models. Share files into Apollo from any app or open what the agent created.

Set up in four steps

  1. Install Hermes and Tailscale

    Install Hermes Agent on your computer. Then install Tailscale on that computer and on your phone, and sign in to the same tailnet.

  2. Run the setup script

    It creates a login (only a hash is stored) and runs the official Hermes backend as a user service on 127.0.0.1. Read it before you run it.

    curl -fsSLO https://raw.githubusercontent.com/wutz-io/apollo-hermes-android/main/scripts/server/setup-hermes-for-apollo.sh
less setup-hermes-for-apollo.sh
bash setup-hermes-for-apollo.sh

  3. Publish it in your tailnet

    Tailscale Serve adds HTTPS with a valid certificate, reachable only inside your tailnet.

    sudo tailscale serve --bg 9119

  4. Sign in with Apollo

    Install the APK, tap “Auth Login”, enter your computer's tailnet address (https://<machine>.<tailnet>.ts.net) and log in.

Manual setup and systems without systemd: README

No cloud in between

  • No telemetry, ads or trackers.
  • Credentials in storage encrypted with the Android Keystore.
  • Regular TLS verification, no open ports needed.
  • Uses only the official Hermes dashboard and backend APIs.
  • The only other request is the optional update check on GitHub.
